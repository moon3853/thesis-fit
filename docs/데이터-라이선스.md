## 문제가 되는 곳: 시세 데이터
- 해외(야후)·국내(네이버·KIS·공공데이터포털) **시세는 전부 ✗**. 무료이면서 상업 이용까지 허용하는 주가 데이터는 사실상 없다.
- 선택지:
  1. **유료 상업 라이선스 API**를 본선 기간만 구독(해외 주식 일봉 수준이면 월 수십 달러대 상품들이 있음 — 상품·약관은 본선 전 확정)
  2. **시험지(합성 데이터)를 정확도 증명의 중심**으로 — 라이선스 문제 없음
  3. **SEC 공시 기반 데이터만으로** 되는 감사(재무 조건, 13F 스타일)는 그대로 공개 데이터로
  4. **주최 측 게시판에 질의** — "비상업 라이선스 데이터를 공모전 프로토타입에 쓰는 것이 허용되는지"(대회 공식 답변은 게시판으로만)

## 기획서에 이미 쓴 우리 연구 숫자는?
- "가설 20개 중 14개", "셀트리온 +37.6%→+28.3%" 등은 야후·네이버 데이터로 **우리가 계산한 분석 결과**다. 원데이터를 재배포하는 것이 아니라 결과 숫자를 인용하는 것이지만, 기획서 부록에 "연구 당시 데이터 출처(야후·네이버, 비상업 연구용)"를 적고 **본선 데모 데이터와 분리**해 두는 게 안전하다.

## 기획서 v3에서 고칠 곳
- ⑤ 데이터 표 "거시(금리·VIX 등) — FRED" → "미 국채금리 등 공공 시리즈 — FRED(저작권 없는 시리즈만)"
- "공개 시세 API 2곳 이상" → "상업 이용 허가된 시세 API(유료, 본선 전 확정)"
- 부록에 연구 숫자의 원데이터 출처·용도 한 줄
